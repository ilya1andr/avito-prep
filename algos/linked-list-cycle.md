# Linked List Cycle (LeetCode 141)

Дата решения: 13 ноября 2026  
Тема: Связные списки, Два указателя (Fast & Slow).

## Условие

Дан `head` связного списка. Нужно определить, есть ли в списке цикл (петля).

Возвращает `true`, если цикл есть, и `false`, если его нет.

## Решение (Алгоритм Флойда «Черепаха и Заяц»)

```python id="s4rj7k"
class Solution(object):
    def hasCycle(self, head):
        # Изначально оба указателя стоят на старте
        slow = head
        fast = head

        # Пока заяц может бежать (не добежал до конца)
        while fast is not None and fast.next is not None:
            slow = slow.next          # Черепаха делает 1 шаг
            fast = fast.next.next     # Заяц делает 2 шага

            # Если они встретились — значит, дорожка закольцована!
            if slow == fast:
                return True

        # Если заяц добежал до конца (None) — цикла нет
        return False
```

## Ключевая идея

Представь, что по круговой дорожке бегут два спортсмена: медленный (черепаха) и быстрый (заяц).

- Черепаха делает 1 шаг.
- Заяц делает 2 шага.
- Если дорожка **закольцована** (есть цикл), заяц рано или поздно обгонит черепаху и они **встретятся** на одном узле.
- Если дорожка **прямая** (цикла нет), заяц добежит до конца (`None`) и остановится.

## Где я споткнулся

- Пришлось вспоминать, как именно проверять условие в `while`. Важно проверять не только `fast is not None`, но и `fast.next is not None`, иначе на последнем шаге программа упадет с ошибкой `AttributeError: 'NoneType' object has no attribute 'next'`.

## Что запомнить

- Этот алгоритм называется **Алгоритм Флойда** (Floyd's Cycle-Finding Algorithm).
- Он работает за **O(n)** времени и использует **O(1)** памяти. Это его главное преимущество перед решением через `set` (хеш-таблицу), которое требует O(n) памяти.

## Сложность

- **Время:** `O(n)`, где n — количество узлов в списке.
- **Память:** `O(1)`, так как мы используем только два указателя.

# Remove Nth Node From End of List (LeetCode 19)

Дата решения: 13 ноября 2026  
Тема: Связные списки, Два указателя (Fast & Slow).

## Условие

Дан `head` связного списка и целое число `n`. Нужно удалить `n`-й узел с конца списка и вернуть его голову.

## Решение (Паттерн «Два указателя с отрывом» + Dummy Node)

```python
class Solution(object):
    def removeNthFromEnd(self, head, n):
        # 1. Создаем фиктивный узел (dummy), который указывает на head
        dummy = ListNode(0)
        dummy.next = head

        # 2. Ставим оба указателя на dummy
        fast = dummy
        slow = dummy

        # 3. Сдвигаем fast на n + 1 шагов вперед
        for _ in range(n + 1):
            fast = fast.next

        # 4. Двигаем fast и slow вместе, пока fast не дойдет до конца
        while fast is not None:
            fast = fast.next
            slow = slow.next

        # 5. slow теперь стоит ровно ПЕРЕД узлом, который нужно удалить
        slow.next = slow.next.next

        # 6. Возвращаем dummy.next (это реальная голова списка)
        return dummy.next
```

## Ключевая идея

Чтобы удалить узел, нам нужно встать ровно **перед ним** (на его предыдущий узел).

Мы используем два указателя: `fast` и `slow`.

1. Сначала `fast` убегает вперед на `n + 1` шагов.
2. Затем мы двигаем их одновременно.
3. Когда `fast` достигает конца списка (`None`), `slow` отстает от него ровно на `n + 1` шаг, что означает, что `slow` стоит на узле, который идет **прямо перед** удаляемым.

## Где я споткнулся

- В первой попытке я не использовал `dummy`. Из-за этого код падал, если нужно было удалить первый элемент (не было переменной `prev`, или `fast` выходил за пределы списка).
- Также я сдвигал `fast` на `n` шагов, а не на `n + 1`. Из-за этого `slow` вставал не перед удаляемым узлом, а на него самого, и удалить его было невозможно.
- Забыл вернуть `head` (или `dummy.next`) в конце функции.

## Что запомнить

- **Dummy Node (Фиктивный узел)** — спасает от ошибок, когда нужно удалить первый элемент. Он всегда стоит перед головой. В конце мы возвращаем `dummy.next`.
- **Отрыв на `n + 1` шаг** нужен именно для того, чтобы `slow` встал на узел *перед* удаляемым.
- Код покрывает все крайние случаи (удаление первого, удаление последнего) без единого `if`.

## Сложность

- **Время:** `O(L)`, где L — длина списка. Мы проходим по списку один раз.
- **Память:** `O(1)`, так как мы используем только два указателя.

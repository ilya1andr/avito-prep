# 3Sum (LeetCode 15)

Дата решения: 2 ноября 2026
Тема: Массивы, Сортировка, Два указателя.

## Условие
Дан массив целых чисел `nums`. Нужно найти все уникальные тройки `[nums[i], nums[j], nums[k]]`, такие что `i != j`, `i != k`, `j != k` и сумма элементов равна `0`.
Решение не должно содержать дубликатов.

## Решение (Сортировка + Два указателя)

```python
class Solution(object):
    def threeSum(self, nums):
        nums.sort()
        ans = []
        n = len(nums)
        
        for i in range(n - 2):
            # Пропускаем дубликаты для первого элемента
            if i > 0 and nums[i] == nums[i - 1]:
                continue
                
            l = i + 1
            r = n - 1
            
            while l < r:
                total = nums[i] + nums[l] + nums[r]
                
                if total == 0:
                    ans.append([nums[i], nums[l], nums[r]])
                    
                    # Пропускаем дубликаты для второго и третьего элементов
                    while l < r and nums[l] == nums[l + 1]:
                        l += 1
                    while l < r and nums[r] == nums[r - 1]:
                        r -= 1
                        
                    l += 1
                    r -= 1
                elif total < 0:
                    l += 1
                else:
                    r -= 1
                    
        return ans
```

## Ключевая идея
- Сортировка — обязательный шаг. Без неё мы не сможем использовать указатели.

- Внешний цикл `i` фиксирует первое число.

- Внутри — классические два указателя `(l и r)` навстречу друг другу (как в задаче Two Sum II).

- Если сумма меньше нуля — двигаем `l` вправо. Если больше — двигаем r влево.

## Где я споткнулся
- Мой первый вариант решения использовал `for i in range(1, len(nums)-1)`, что ломало логику (`i` должен быть первым элементом тройки).

- Вместо пропуска дубликатов «на лету» я использовал проверку `if arr not in ans`. Это вызывало `Time Limit Exceeded`, так как поиск в списке занимает `O(n)` времени на каждой итерации.

- Важно не забыть пропустить дубликаты для `i`, `l` и `r`, чтобы ответ не содержал одинаковых троек.

## Что запомнить
Паттерн «Сортировка + Два указателя» идеально подходит для задач, где нужна сумма элементов в массиве.
Чтобы не вылететь по времени, дубликаты нужно пропускать сдвигом указателей (`while l < r and nums[l] == nums[l+1]`), а не проверкой `if x in list`.

## Сложность
- Время: O(n^2), где n — длина массива. Сортировка занимает O(n log n), а двойной цикл — O(n^2).

- Память: O(n) или O(log n) в зависимости от реализации сортировки (без учета памяти под ответ).

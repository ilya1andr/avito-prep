# Product of Array Except Self (LeetCode 238)

Дата решения: 2 ноября 2026
Тема: Массивы, Префиксные произведения.

## Условие
Дан массив целых чисел `nums`. Нужно вернуть массив `answer`, где `answer[i]` равно произведению всех элементов массива `nums`, кроме `nums[i]`.
**Ограничение:** нельзя использовать деление, и алгоритм должен работать за O(n).

## Решение (Два прохода)

```python
class Solution(object):
    def productExceptSelf(self, nums):
        n = len(nums)
        ans = [1] * n

        # 1. Проход слева направо: произведение всех элементов СЛЕВА
        left_product = 1
        for i in range(n):
            ans[i] = left_product
            left_product *= nums[i]

        # 2. Проход справа налево: произведение всех элементов СПРАВА
        right_product = 1
        for i in range(n - 1, -1, -1):
            ans[i] *= right_product
            right_product *= nums[i]

        return ans
```

## Ключевая идея
Запрет на деление (а также возможные нули в массиве) не позволяет просто перемножить всё и поделить на текущий элемент.
Вместо этого мы используем **префиксные и суффиксные произведения**.
1. Идем слева направо и записываем в `ans` накопленное произведение всех чисел слева от текущего.
2. Идем справа налево, вычисляем произведение всех чисел справа и умножаем его на то, что уже лежит в `ans`.

## Где я споткнулся
- В первом варианте я использовал два цикла `while` (вложенных в цикл `for`). Это дало сложность **O(n^2)** и привело к `Time Limit Exceeded` на больших тестах (как в примере с 10 000 элементов).
- Нужно было объединить вычисления в два линейных прохода по массиву без вложенных циклов.

## Что запомнить
- Паттерн «Префиксные произведения» работает так же, как и «Префиксные суммы», только с умножением.
- Если задача требует O(n) и запрещает деление, скорее всего, нужно использовать два прохода (слева-направо и справа-налево).
- Переменная `left_product` (и `right_product`) накапливает результат «на лету», что позволяет сэкономить память.

## Сложность
- **Время:** O(n), так как мы проходим по массиву ровно два раза.
- **Память:** O(1) дополнительной памяти (не считая массива `ans`, который обязателен по условию).

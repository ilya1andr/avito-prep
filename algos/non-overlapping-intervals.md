# Non-overlapping Intervals (LeetCode 435)

Дата решения: 8 ноября 2026  
Тема: Жадный алгоритм (Greedy), Сортировка, Массивы.

## Условие

Дан массив интервалов `intervals`, где `intervals[i] = [start_i, end_i]`.

Нужно вернуть **минимальное количество интервалов**, которые нужно удалить, чтобы все оставшиеся интервалы не пересекались.

## Решение (Жадный алгоритм + Сортировка по концу)

```python
class Solution(object):
    def eraseOverlapIntervals(self, intervals):
        k = 0

        # 1. Сортируем интервалы по их КОНЦУ (правой границе)
        intervals.sort(key=lambda x: x[1])

        # 2. Идем по массиву, начиная со второго элемента
        for i in range(1, len(intervals)):
            # Если начало текущего интервала меньше конца предыдущего, они пересекаются
            if intervals[i][0] < intervals[i - 1][1]:
                k += 1

                # Мы "удаляем" текущий интервал, но чтобы не сломать проверку для следующего,
                # мы приравниваем его конец к концу предыдущего (оставляем границу предыдущего)
                intervals[i][1] = intervals[i - 1][1]

        return k
```

## Ключевая идея

Это задача на **жадный алгоритм**. Чтобы удалить минимум интервалов, нам нужно оставить максимум непересекающихся.

Для этого всегда выгодно выбирать интервалы, которые **заканчиваются раньше**. Чем раньше заканчивается интервал, тем больше места остается для следующих.

1. Сортируем по правому краю (`x[1]`).
2. Идем по массиву. Если текущий интервал пересекается с предыдущим (`start < prev_end`), значит, один из них точно надо удалить.
3. Так как мы отсортировали по концу, предыдущий интервал заканчивается раньше. Поэтому мы удаляем **текущий** (`k += 1`), а его конец заменяем на конец предыдущего (чтобы следующий интервал проверялся на пересечение с «актуальной» границей).

## Что запомнить

- В задачах на интервалы есть два подхода к сортировке:
    - Сортировать по **началу** (`x[0]`) — для задач на объединение (как `Merge Intervals`).
    - Сортировать по **концу** (`x[1]`) — для задач на максимизацию количества непересекающихся интервалов (как эта).
- Жадный алгоритм не всегда требует физического удаления элементов. Иногда достаточно просто "запомнить" новые границы

## Сложность

- Время: O(n log n), где n — количество интервалов (доминирует сортировка).

- Память: O(1) или O(log n) в зависимости от реализации сортировки (без учета памяти под входные данные).

# Merge Intervals (LeetCode 56)

Дата решения: 1 ноября 2026
Тема: Массивы, Сортировка, Слияние интервалов.

## Условие
Дан массив интервалов `intervals`, где `intervals[i] = [start_i, end_i]`.
Нужно объединить все пересекающиеся интервалы и вернуть массив непересекающихся интервалов, которые покрывают все входные интервалы.

## Решение (Сортировка + Один проход)

```python
class Solution(object):
    def merge(self, intervals):
        # 1. Сортируем интервалы по началу
        intervals.sort(key=lambda x: x[0])
        
        # 2. Создаем результирующий массив, кладем туда первый интервал
        merged = [intervals[0]]
        
        # 3. Идем по остальным интервалам
        for current in intervals[1:]:
            # Берем последний добавленный интервал
            last_merged = merged[-1]
            
            # Если начало текущего <= конца последнего (они пересекаются)
            if current[0] <= last_merged[1]:
                # Обновляем конец последнего на максимум из двух концов
                last_merged[1] = max(last_merged[1], current[1])
            else:
                # Если не пересекаются, просто добавляем новый интервал
                merged.append(current)
                
        return merged
```

## Ключевая идея
- Сортировка — это главный ключ. Если отсортировать интервалы по началу (`start`), то любые пересекающиеся интервалы будут стоять рядом.
- Слияние на лету: мы храним последний добавленный интервал в `merged[-1]`. Если начало нового интервала `current[0]` меньше или равно концу последнего `last_merged[1]`, значит они пересекаются. Мы просто расширяем конец последнего интервала: `max(last_merged[1], current[1])`.

## Где я споткнулся (мой первый вариант)
- Сначала я пытался решить задачу через массив-счетчик `arr = [0]*10**4`, отмечая каждый день в интервале.
- Это работает, но:
Огромный расход памяти (O(max(intervals))).
Очень медленно (Time Limit Exceeded на больших тестах).
Падает с ошибкой, если в интервалах есть отрицательные числа (индексы массива не могут быть отрицательными).
Вывод: для интервалов нужен подход со сортировкой, а не с подсчетом.

## Что запомнить
- Задачи на интервалы почти всегда решаются через сортировку по началу.

- Слияние интервалов — это классический паттерн: if curr_start <= prev_end: expand prev_end.

- В Python списки передаются по ссылке, поэтому last_merged[1] = max(...) меняет данные прямо в массиве merged.

## Сложность
- Время: O(n log n), где n — количество интервалов (доминирует сортировка).

- Память: O(n) — для хранения результата (в худшем случае, если нет пересечений, результат равен исходному массиву).

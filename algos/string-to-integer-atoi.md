# String to Integer (atoi) (LeetCode 8)



Дата решения: 19 октября 2026

Тема: Строки, симуляция парсинга.



## Условие

Реализовать функцию myAtoi(string s), которая преобразует строку в 32-битное целое число.

Правила:

1. Игнорировать пробелы в начале.

2. Учесть знак '+' или '-'.

3. Читать цифры, пока не встретится нецифровой символ.

4. Если число выходит за пределы [-2^31, 2^31 - 1], вернуть граничное значение.



## Решение



```python

class Solution(object):

   def myAtoi(self, s):

       if len(s) == 0: 

           return 0

       

       i, n = 0, len(s)

       while i < n and s[i] == ' ':

           i += 1

       if i == n: 

           return 0

       

       sign = 1

       if s[i] == '-':

           sign = -1

           i += 1

       elif s[i] == '+':

           i += 1

           

       ans = 0

       while i < n and s[i].isdigit():

           ans = ans * 10 + int(s[i])

           i += 1  

           

       ans *= sign

       INT_MAX = 2**31 - 1

       INT_MIN = -(2**31)

       

       if ans > INT_MAX: 

           return INT_MAX

       elif ans < INT_MIN:
           return INT_MIN

           

       return ans
   ```



## Ключевая идея

Пошаговая симуляция:



Двигаем указатель i вперед, пока не встретим не-пробел.



Проверяем знак: если минус, ставим sign = -1. Обязательно используем elif для плюса, чтобы не проверять его, если уже нашли минус, и не упасть с ошибкой на строке "-".



В цикле собираем число: ans = ans * 10 + int(s[i]). И не забываем i += 1, иначе будет бесконечный цикл.



В конце проверяем, не вышли ли мы за пределы 32-битного int.

# Reverse Linked List (LeetCode 206)

Дата решения: 13 ноября 2026  
Тема: Связные списки, Указатели.

## Условие

Дан `head` связного списка. Нужно развернуть список (сделать так, чтобы последний элемент стал первым) и вернуть новую голову.

## Решение (Итеративное)

```python
class Solution(object):
    def reverseList(self, head):
        prev = None
        curr = head

        while curr is not None:
            next_node = curr.next    # 1. Запоминаем следующий узел
            curr.next = prev         # 2. Разворачиваем связь
            prev = curr              # 3. Сдвигаем prev вперед
            curr = next_node         # 4. Сдвигаем curr вперед

        return prev
```

## Ключевая идея

Чтобы развернуть стрелки, нам нужны **три указателя**:

1. `prev` — куда мы цепляем текущий узел (изначально `None`, так как новый хвост будет указывать в пустоту).
2. `curr` — текущий узел, который мы обрабатываем.
3. `next_node` — чтобы не потерять оставшуюся часть списка, когда мы разорвем связь.

Мы идем по списку, переворачиваем стрелку `curr.next = prev`, а затем сдвигаем `prev` и `curr` на шаг вперед.

## Где я споткнулся

- Сначала было сложно понять, как не потерять остаток списка. Решение: всегда сохранять `curr.next` в переменную `next_node` *до* того, как перезаписать `curr.next`.
- Забывал, что в конце нужно вернуть `prev` (а не `curr`, который станет `None`).

## Что запомнить

- Это базовая задача, которую нужно уметь писать наизусть. Без нее не решить более сложные задачи на списки (например, Reorder List).
- В Python нет явных указателей (как в Go), но объекты передаются по ссылке, поэтому `curr.next = prev` работает так же, как в языках с указателями.

## Сложность

- **Время:** `O(n)`, один проход по списку.
- **Память:** `O(1)`, используем только три переменные.

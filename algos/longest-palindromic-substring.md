\# Longest Palindromic Substring (LeetCode 5)



Дата решения: 19 октября 2026

Тема: Строки, расширение от центра (Expand Around Center).



\## Условие

Дана строка `s`. Нужно найти самую длинную подстроку-палиндром (которая читается одинаково слева направо и справа налево) и вернуть её.



\## Решение



```python

class Solution(object):

&#x20;   def longestPalindrome(self, s):

&#x20;       if not s:

&#x20;           return ""

&#x20;           

&#x20;       mx = 1

&#x20;       start = 0

&#x20;       

&#x20;       def expand(l, r):

&#x20;           # Расширяемся от центра, пока буквы совпадают

&#x20;           while l >= 0 and r < len(s) and s\[l] == s\[r]:

&#x20;               l -= 1  # влево

&#x20;               r += 1  # вправо

&#x20;           # Когда цикл остановился, l и r ушли на 1 шаг лишнего

&#x20;           return r - l - 1

&#x20;           

&#x20;       for i in range(len(s)):

&#x20;           # 1. Нечетный палиндром (центр — символ): "aba"

&#x20;           len1 = expand(i, i)

&#x20;           # 2. Четный палиндром (центр — между символами): "abba"

&#x20;           len2 = expand(i, i + 1)

&#x20;           

&#x20;           cur\_mx = max(len1, len2)

&#x20;           

&#x20;           if cur\_mx > mx:

&#x20;               mx = cur\_mx

&#x20;               # Вычисляем индекс начала найденного палиндрома

&#x20;               start = i - (cur\_mx - 1) // 2

&#x20;               

&#x20;       return s\[start : start + mx]

## Где я споткнулся
В самой первой попытке двигал указатели внутрь (l += 1, r -= 1), из-за чего палиндром не мог расшириться.



Не мог понять, почему возвращается пустая строка. Ошибка была в формуле длины: писал r - l + 1 вместо r - l - 1.

Почему минус? Потому что цикл while останавливается, когда l и r уже указывают на несовпадающие символы (или вышли за границы). То есть они ушли на 1 шаг лишнего в обе стороны (всего 2 шага).

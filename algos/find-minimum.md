# Find Minimum in Rotated Sorted Array (LeetCode 153)

Дата решения: 27 октября 2026
Тема: Бинарный поиск.

## Условие
Дан "прокрученный" отсортированный массив. Найти минимальный элемент за O(log n).

## Решение (Классическое)

```python
class Solution(object):
    def findMin(self, nums):
        l = 0
        r = len(nums) - 1
        
        while l < r:
            mid = (l + r) // 2
            
            if nums[mid] > nums[r]:
                l = mid + 1
            else:
                r = mid
                
        return nums[l]
   ```
## Ключевая идея
Мы сравниваем `nums[mid]` с правым краем `nums[r]`.

- Если `nums[mid] > nums[r]`, значит середина находится в левой (большой) половине, а минимум точно правее. Двигаем `l = mid + 1`.

- Если `nums[mid] <= nums[r]`, значит от `mid` до `r` всё отсортировано, и минимум находится либо в `mid`, либо левее. Двигаем `r = mid`.
Цикл `while l < r`заканчивается, когда указатели сходятся на минимальном элементе.

## Где я споткнулся
Сначала решал через переменную mn и сравнивал `nums[mid]` с левым краем nums[l]. Это работало, но было сложнее. Классический подход через nums[r] надежнее и не требует доп. переменных.

## Что запомнить
Сравнение с правым краем (`nums[r]`) — это "золотой стандарт" для этой задачи.

Условие `while l < r` (без =) правильное, так как когда они сойдутся, это уже и есть ответ.

## Сложность
Время: O(log n).
Память: O(1).

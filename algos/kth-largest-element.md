# Kth Largest Element in an Array (LeetCode 215)

Дата решения: 8 ноября 2026  
Тема: Сортировка, Куча (Heap), Min-Heap.

## Условие

Дан массив целых чисел `nums` и число `k`. Нужно найти `k`-й по величине элемент в массиве (не уникальный, а по счету).

**Пример:**

`nums = [3,2,1,5,6,4], k = 2` → ответ `5`.

## Решение (Min-Heap на Python)

```python
import heapq

class Solution(object):
    def findKthLargest(self, nums, k):
        heap = []

        for num in nums:
            heapq.heappush(heap, num)  # Добавляем число

            # Если в куче стало больше k элементов,
            # выкидываем самый маленький (он всегда наверху)
            if len(heap) > k:
                heapq.heappop(heap)

        # В конце в куче остались ровно k самых больших элементов.
        # А так как это Min-Heap, наверху (heap[0]) находится самый маленький из них.
        # Это и есть k-й по величине элемент!
        return heap[0]
```

## Ключевая идея

Мы используем **Min-Heap** (минимальную кучу) размера `k`.

Мы идем по массиву и добавляем каждый элемент в кучу. Как только размер кучи превышает `k`, мы выкидываем самый маленький элемент (он всегда находится на вершине кучи).

Таким образом, в куче всегда хранятся **только `k` самых больших элементов**, которые мы встретили на данный момент.

Когда мы дойдем до конца массива, на вершине кучи окажется **самый маленький из этих `k`** — а это и есть ровно `k`-й по величине элемент во всем массиве.

## Где я споткнулся

- Пришлось вспоминать, как работает `heapq` в Python. Оказалось, что для того, чтобы получить K-й максимальный элемент, нам нужна именно **Min-Heap** (куча, наверху которой минимум). Это контринтуитивно, но логично: мы держим в куче топ-K элементов, а минимум из этого топа (вершина) и есть K-й элемент.
- В Go эта задача решается сложнее, так как там нет встроенной кучи. Нужно реализовывать интерфейс `heap.Interface` (методы `Len`, `Less`, `Swap`, `Push`, `Pop`) и использовать указатели (`*IntHeap`), чтобы изменения применялись к оригинальной структуре.

## Что запомнить

- **Min-Heap** всегда держит минимум наверху. Если мы хотим найти K самых больших элементов, мы используем Min-Heap размера K.
- `heapq.heappush(heap, item)` — добавить элемент.
- `heapq.heappop(heap)` — извлечь минимальный элемент.
- Сложность алгоритма — **O(n log k)**, где `n` — количество элементов в массиве. Это быстрее, чем полная сортировка `O(n log n)`, если `k` маленькое. Память — `O(k)`.

## Сложность

- **Время:** `O(n log k)`
- **Память:** `O(k)`
